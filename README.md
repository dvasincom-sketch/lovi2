# lovi2 — репозиторий развёртывания Lovi

Тонкая оболочка для деплоя. **Продуктового кода здесь нет** — он живёт в:
- `lovi-web` (React-витрина, собирается в статику);
- `insalon` (FastAPI: API + отдача статики).

`Dockerfile` собирает единый образ: клонирует оба публичных репозитория по закреплённой
ссылке (`LOVI_WEB_REF` / `INSALON_REF`), строит фронт, ставит бэкенд, кладёт `dist` в
`WEB_DIR`. Один контейнер отдаёт и `/api/*`, и React-приложение (SPA-fallback в `app/main.py`).

## Локальная проверка
1. `cp .env.example .env` и заполнить секреты.
2. `docker compose up --build`
3. Открыть http://localhost:8000 (витрина), http://localhost:8000/healthz (проверка API).

## Деплой на Timeweb
Timeweb Cloud App (Docker) собирает этот репозиторий, переменные окружения задаются в панели
(см. `.env.example`). Порт — из `PORT` (по умолчанию 8000). Для нового релиза продукта —
поднять `LOVI_WEB_REF` / `INSALON_REF` на нужный коммит/тег.
